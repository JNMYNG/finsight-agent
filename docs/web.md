# 로컬 웹 앱 — Day 3

## 실행

Python 3.11, 프로젝트 루트, 기존 `.env`의 OpenDART/OpenAI 키를 사용한다.
키를 입력받는 웹 위젯은 없으며 설정 오류에도 키 값이나 SDK 예외를 표시하지 않는다.

```bash
uv sync --extra dev --locked
# 최초 RAG 사용 시 필요. 이미 색인했다면 생략한다.
.venv/bin/python -m finsight rag-index
.venv/bin/streamlit run streamlit_app.py
```

주소는 `http://127.0.0.1:8501`이다. 기본적으로 루프백에만 바인딩한다.
종료는 터미널에서 Ctrl+C. 다른 포트가 필요하면 `--server.port 8502`를 추가한다.
OpenAI Tool 선택 및 임베딩 요청에는 API 비용이 발생한다.

## 사용법과 지원 범위

- 기업: 삼성전자, SK하이닉스 중 1~2곳.
- 재무: 2015년부터 직전 사업연도까지, 연간 사업보고서(11011), 명시적인 CFS 또는 OFS.
  UI의 선택 가능 연도가 모두 실데이터 검증됐다는 뜻은 아니다. 기업·연도별로 누락될 수 있다.
- 사업연도: 최대 3개. 여러 연도를 선택하면 실제 Tool 반환값으로 추이 차트를 표시한다.
- RAG: 두 기업의 2024년 사업보고서 II/IV 서술만 검색한다. 다른 연도 재무만 조회할 때는 해제한다.
  복수 연도에 2024년이 포함된 경우에도 문서 근거는 2024년만 제공한다.
- 예시 질문: "삼성전자와 SK하이닉스의 2024년 영업이익률을 비교하고,
  사업보고서에서 실적 차이와 관련된 근거를 찾아 주세요."
- 질문에 기업·연도·기준을 명시했다면 화면 선택과 일치시킨다. 분반기 질문은 지원하지 않는다.
  일반 채팅이나 임의 기업 분석 UI가 아니다.

`재무 대시보드`는 최신 선택 연도의 카드, 전체 조회 비교표, 지표별 차트, 공시 링크를 제공한다.
금액은 정확한 원문 통화 금액으로 표시하며 단위 축약을 위한 별도 계산은 하지 않는다.
표·카드는 Decimal 문자열, 차트만 부동소수점 표시값을 사용한다. 외화 금액을 KRW 차트에 섞지 않는다.
없는 항목은 `데이터 없음`과 경고로 표시하고 0 또는 LLM 추정값으로 대체하지 않는다.

`사업보고서 근거`에는 발췌 문장·기업·연도·접수번호·원문 링크·제목 경로·XML 위치를 표시한다.
문단 전체는 접어서 볼 수 있다. 원문은 데이터이며 문서 명령을 모델에 전달하거나 실행하지 않는다.
서술의 원문 수치는 Python 계산값이 아니며, 문장 관련성만으로 인과관계를 확정하지 않는다.

`Agent 실행`은 실제 호출 순서·도구명·성공 여부·소요 시간을 표시한다.
원시 인자·인증 헤더·SDK traceback·민감 로그는 브라우저에 출력하지 않는다.
로컬 `logs/web-agent.jsonl`은 기존 마스킹 감사 로그를 사용하고 Git에서 제외한다.

## 상태와 오류

- 정상 완료: Agent가 완료됐고 화면의 요청 범위에 필요한 재무·문서 결과가 확보됐다.
- 일부 성공: 일부 연도·기업·재무 항목 또는 RAG 근거 누락, 도구 일부 실패 등.
- 실패: 검증된 결과가 없거나 설정·API·로컬 실행 오류.
- 조건 확인 필요 / 호출 한도 도달: 기존 Agent 상태를 별도로 표시한다.

질문은 1~2,000자, 조건은 실행 전에 검증한다. 모델이 화면 밖 기업·연도·보고서·기준을 요청하면
실제 도구/API 호출 전에 차단한다. 재무·문서 결과도 화면 선택과 기업 코드·출처를 다시 대조한다.
근거가 없으면 원인 추론 대신 근거 부족을 안내한다. 색인 부재는 터미널의 `rag-index`로 준비한다.

완료 결과는 세션에만 보관한다. 차트 선택이나 펼침/접기는 API를 재실행하지 않는다.
조건을 바꾸면 이전 결과임을 알리고, `분석 실행`을 다시 눌렀을 때만 유료 요청을 실행한다.
새 실행이 실패했을 때 과거 성공 결과가 새 결과처럼 남지 않도록 이전 결과를 제거한다.
API 클라이언트는 요청별 생성/종료하며 전역 캐시에 키·클라이언트를 넣지 않는다.

## 검증

자동화 (실제 키·외부 네트워크 미사용):

```bash
.venv/bin/pytest --cov=finsight --cov-report=term-missing
.venv/bin/ruff check src tests scripts streamlit_app.py
.venv/bin/ruff format --check src tests scripts streamlit_app.py
```

실제 API와 Streamlit AppTest를 함께 사용하는 별도 검증:

```bash
.venv/bin/python scripts/verify_web_live.py
.venv/bin/python scripts/verify_web_live.py --years 2024 --basis OFS --no-rag
```

첫 명령은 두 기업 2022~2024년 CFS 비교와 2024년 RAG를 검증한다.
두 번째는 두 기업 2024년 OFS 비교 (RAG 해제)를 검증한다.
화면의 재무값을 독립 Day 1 조회와 비교하고, 문서 발췌·해시·메타데이터·위치를 저장된 실제 원문과
다시 대조한다. 링크와 차트 표시 및 차트 변경 시 API 재실행 방지도 검사한다.
이는 headless AppTest 검증이며 실제 브라우저 클릭 테스트와 구분한다.

실행 결과와 실제 발견한 오류는 [설계·검증 기록](decisions.md)의 Day 3 절에 기록한다.
다른 연도 RAG·임의 기업·보고서 전체·분반기 UI·인과 추론·인증/다중 사용자 서비스·Docker·배포는
구현 범위 밖이다. LLM Tool 선택은 비결정적이며 모든 자연어 표현의 성공을 보장하지 않는다.
